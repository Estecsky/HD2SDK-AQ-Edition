# [AQ_Ex](https://space.bilibili.com/3493298962434150)个人魔改版

> 项目最初是为个人使用而修改，目的是解决原版以及社区版中一些体验欠佳的问题。
同时在原版的基础上添加了一些新功能，以更加适合中文Modder的使用习惯。

部分修改功能：
- 添加多种材质模板(泛光，流光，advanced，alpha clip，玻璃等)
- 添加Patch重命名功能与新建Patch时调整序号功能，支持自动填充为基础资产的重命名
- 材质参数功能
- 添加导入TGA和PNG纹理的功能，将会在保存时自动转换为DDS
- 添加自定义Patch导出目录和导出文件目录预览功能，写入Patch后会显示打开输出目录的按钮
- 可将Patch导出为Zip文件功能
- 设置游戏data目录后，可从插件中搜索中文收集表存在的备注条目并选择载入
- 手动更新本地搜索Archive ID 中文条目功能
- 其他UI优化（可自由切换新旧布局，Archive条目种类可折叠，更便捷载入基础资产）
- 添加快捷转移功能与转移标记属性按钮
- 半精度权重精确闭合，护甲分部件不再有裂缝
- 动画Modding支持，可以为原版骨架添加自定义外部动画骨并保存动画
- 完整的综合护甲系统配套功能支持：
   - 独立保存基础和资源隔离
   - 组差分与自由搭配差分
   - 胸甲及未保存甲片清理
   - 独立辅助骨 Rig 与公共 Rest 修正
   - 自动整合 PhysBone
   - 身体共享物理解算
   - 衣物姿态驱动导出
   - 独立材质包
   - 身体/头盔配套组 ZIP 合并

# 适配 Blender 4.0–5.2
同一 Blender 会话只能启用一个 SDK。
